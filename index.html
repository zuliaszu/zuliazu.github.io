About me

In practice

How I approach AI security

Practical checks for reviewing an AI application.

  1. 01

    Start with the application

    Look at the data, users and actions the application supports. Model behaviour matters, but so do the access controls and software around it.

  2. 02

    Treat retrieved content as untrusted

    Documents and tool responses can contain instructions an attacker wants the model to follow. Check how the application handles that content before it reaches an agent.

  3. 03

    Limit what agents can do

    Give agents only the tools and permissions they need. Require human approval for consequential actions, and keep records of what ran.

  4. 04

    Make findings reproducible

    Record the input, observed behaviour and security impact. Give the engineering team enough detail to reproduce the issue and test the fix.
